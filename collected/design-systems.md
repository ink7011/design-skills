# 公开设计系统 / 品牌规范站点

值得通读的公开设计系统与品牌规范。学习别人怎么定义 token、怎么写使用规则、怎么防误用。

## 怎么读这些规范（个人习惯）

1. 先看 token 命名和分层方式（reference → semantic → component）
2. 再看"misuse / don'ts"章节——禁止用例暴露的约束比允许用例更有信息量
3. 最后看无障碍章节的量化门槛（对比度、最小触控区）——可执行的规则才是规则
