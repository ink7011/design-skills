# 规则先行：多等级视觉资产的规则制定法

> 沉淀自真实实践的通用方法论，与任何具体项目无关。
> 适用场景：任何"分等级的对外视觉资产"（认证/会员/等级标识体系）。

## 为什么规则先行

多等级视觉资产的争议 90% 不是审美问题，是**语义问题**：这档和那档差在哪、
谁能用、失效了怎么办。先把这些写成规则，设计变成规则的执行，
每个视觉争论都能回到规则表裁决，而不是互相说服审美。

## 必须先回答的规则（按顺序）

1. **语义限定**：这个标识认证/表达的是什么？写三句限定 + 五句"不暗示"
   （不为全部产品背书 / 不担保结果 / 不是永久 / 不含未公开权利 / 不等同产品声明）
2. **免责声明**：一句话版，随发放页展示（参考大型平台伙伴计划的官方句式）
3. **身份 ≠ 授权**：身份标识不是商业授权——两层分开，法务要过目
4. **使用资格**：谁能用 + **谁不能用**（"不构成资格"清单：试用/采购过/被报道/
   参过会/前员工……都不等于资格）
5. **生命周期**：有效 / 复审中 / 降级 / 撤销四态下标识分别怎么处理；
   状态与下载权限绑定；撤销后已发布物料的移除期限
6. **命名决策**：档位命名与状态词冲突检查（同一词既当档位名又当状态名 → 歧义）
7. **不进图形的信息**：年份/区域/名额/商业条款/能力清单——全部放验证系统，不放图形

## 行业共性（大厂做法的稳定规律）

- 标识必须**绑定资格**，不是公开素材下载（下载需登录，公开页只放预览+规则）
- 伙伴标识与产品 powered 声明是**两类资产**，永不合并
- 信息层级：品牌方标识 → 伙伴身份 → 档位
- 生命周期可工程化：复审期停用、状态变更 24h 内同步、证明类文件短有效期
- 主标识不带年份（时效在验证系统）；只有"获奖类"带年份
- 禁止改色/重绘/暗示未批准背书/资格失效后继续使用——四家全是这么写的
