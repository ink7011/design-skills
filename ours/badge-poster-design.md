# 徽章 / 海报图片设计工艺（Badge & Poster Image Craft）

> 沉淀自真实实践的通用工艺，与任何具体项目无关。覆盖认证徽章体系与平面海报类
> 图片资产：调研 → 规则 → 生成 → 多版本导出 → 使用规范。

## A. 认证徽章（Badge System）

### 1. 规则先行：徽章必须回答三问

| 问题 | 表达 | 风险 |
|---|---|---|
| 谁认证？ | 官方 logo + 完整品牌名（认证方） | 缩写自立门户会稀释授权感 |
| 认证谁？ | 被批准的伙伴公司（非产品、非个人） | 暗示为产品/项目结果背书是法务风险 |
| 认证什么？ | 伙伴身份 +（可选）等级 | 能力声明单独走，不进主徽章 |

**五不做**：不做付费即得的"加盟章"；不把产品级声明（"Powered by X"）当认证；
不写国家/区域/独家/名额进徽章；不写商业承诺；不写有效期（放数据库/门户记录）。

### 2. 竞品调研五维表（只采官方页面）

| 维度 | 记什么 | 决定什么 |
|---|---|---|
| Shape | 横向 lockup / 盾 / 圆章 | 载体与场景适配 |
| Typography | 是否官方字标、可否重组 | 文字是否进徽章 |
| Color | 品牌色系 + 对比度要求 | 配色与反白版本 |
| Hierarchy | 标识→身份→等级 的层级 | 信息架构 |
| Usage rules | 不可改项、授权可撤销 | 使用规范条款 |

通用结论：横向圆角 lockup > 盾牌/圆章（官网、deck、目录、marketplace 卡片通吃）；
信息层级最稳的是 `品牌标识 → 伙伴身份 → 等级`；所有大厂都禁止改色/重绘/失效后继续用。

### 3. 命名与拆分

- **身份 + 等级 + 能力**三者拆开：主徽章只做身份；等级做变体；能力做门户标签。
- 命名歧义检查："Certified" 既是等级又是状态时，避免 `Certified Certified Partner`
  这类叠词——等级名或状态名至少一方让位（Authorized / Verified / Registered 备选）。
- 等级公开性未确认前，变体只做不发放。

### 4. 视觉等级映射

- 等级 → 品牌色使用等级：顶级=黑白主色占比最高 + 小面积点缀色；
  次级=点缀色用于状态；再次=黑白与点缀色均衡。**最低一档不对应认证**（留给联名/传播）。
- 等级标识（S/A/B）只做视觉内部约定，不作为公开文案。

### 5. 生成工艺（SVG）

- **官方 logo 只能用官方资产文件**：path 逐字复制，禁止重绘/简化/换色；
  交付前做字符串比对校验。
- 结构模板（960×300 viewBox）：
```
圆角描边容器 → 左侧品牌色块(tile)内放官方 logo → 1px 分隔线(低透明)
→ 右侧两行文字：小字状态行(字距加宽) + 大字身份行(重字重)
```
- 字体：无官方指定字体时用 Inter/system sans；文字必须转路径或随附字体要求。
- 渐变注意 `gradientUnits="userSpaceOnUse"` 的局部坐标系坑（详见 svg-craft.md）；
  同页多 SVG 的渐变/裁切 `id` 必须唯一。

### 6. 变体交付矩阵

| 资产 | 说明 |
|---|---|
| 主徽章 dark / light | 深色底用 dark，浅色底用 light |
| 等级变体 ×N | 每个公开等级一套 dark+light |
| 紧凑版（可选） | 目录/头像角标用，不对外单独发放 |
| 格式 | SVG（矢量）+ PNG（透明底），双份齐交 |

### 7. 导出管线（SVG → PNG 透明底）

无头浏览器截图即可，无需装重型工具：

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless=new --disable-gpu --hide-scrollbars \
  --default-background-color=00000000 \        # 关键：透明背景
  --screenshot=out.png --window-size=1920,600 \
  "file:///abs/path/badge.svg"
```
批量导出写个 Node 脚本循环调用即可；2x 分辨率用 `--force-device-scale-factor=2`。

### 8. 使用规范文档（发放即附）

结构：使用场景表（官网/联合 PR/deck/目录/案例页）→ 最小尺寸（数字端 ≥160px 宽）
→ 安全距离（≥ logo tile 高度的 1/4）→ 不可修改项（颜色/比例/文案/logo/边框/形状）
→ 明暗版本选择规则 → **授权与撤销**（仅批准伙伴、仅批准范围、资格失效即停用）。

### 9. 防滥用三原则

1. 徽章绑定资格，不是素材下载站——下载入口放认证状态之后。
2. 候选期/谈判期一律不展示（门户文案明说"具名伙伴仅批准后出现"）。
3. 伙伴误用时按使用规范沟通，不改资产迁就误用。

## B. 海报 / 平面图片（Poster & Flat Graphics）

### 1. 单色克制基线
科技/企业语境海报优先单色系（近黑 + 一支点缀色），彩色数量 ≤ 2；
信息密度高于装饰密度——先排信息层级，再补氛围。

### 2. 版式网格
- 12 列网格，关键元素跨 4/6/8 列；外边距 ≥ 列宽。
- 字号阶梯 3 档封顶（如 96 / 40 / 16），档间比 ≥ 2.2:1。
- mono 小字做"技术标注"（编号/日期/编号体系），与主标题形成材质对比。

### 3. 双规格输出
屏显（16:9 / 1:1 / 9:16 三裁切，PNG/WebP）+ 印刷（CMYK、300dpi、出血 3mm）。
同一版式先做母版，再切规格，不为每个规格重排。

### 4. LOGO 使用同徽章红线
官方资产原样使用、留白 ≥ 安全区、不在 logo 上叠元素；
海报若需品牌图形化，用"背后加层"手法（暗色挤出/投影/局部光）而非改动 logo 本体。

### 5. 验收回路
图片资产同样走"看图才算完成"：导出后必须开图目检（缩放到最小使用尺寸再看一遍），
有条件跑一次视觉 QA 回路（详见 visual-qa-loop.md）。
