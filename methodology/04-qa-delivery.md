# 04 · QA 与交付：视觉验收回路 + 评审页 + 一键启动

## 视觉 QA 回路（最重要的一条经验）

**永远不要只看代码就说"做完了"。** 回路：

1. 导出 PNG
2. 上传到图床拿到 URL（注意：**同名文件会被缓存返回旧图**——换全新文件名再传）
3. 视觉模型逐项验收（给具体问题清单：渐变是否渲染、圆角有无方角突出、
   文字对比、元素是否等宽、有无错位溢出）
4. 结论必须逐条对照问题清单，不通过就修，通过才算完成

验收 prompt 要**问具体问题**（"左 1/3 是否有渐变块且圆角一致"），
不要问开放问题（"好看吗"）。

## 渲染检查用无头浏览器，不用有头浏览器截图

- 页面图片加载验证：无头 Playwright 监听 requestfailed + 逐 img 检查 naturalWidth
- 文字宽度实测：setContent 注入 SVG，getComputedTextLength()
- 深浅模式验证：emulateMedia({colorScheme}) 实测 body 背景色，别信"应该没问题"

## 评审页（每轮设计的标配产物）

每轮设计出一个静态 HTML 对比页：

- 顶部：决策依据 + 用户修订历史（Rev A/B/C...，每条注明改了什么为什么改）
- 差异逻辑表格（每档一句"说得出"的设计语言）
- 全部资产网格展示（深浅成对）
- 技术要点（clipPath / 渐变坐标 / 字体栈）
- 图片 src 加 `?v=xxx` 版本参数防浏览器缓存旧图

评审页 + 文档中心首页（index.html 列出所有轮次/规范/资产入口）+ 
双击启动器（.command：端口活着就直接 open，否则起 http.server 再 open）=
评审体验闭环：任何人双击一个文件就能看到全部设计。

## 导出规范

- SVG → PNG：无头浏览器截图 SVG 元素，viewport = SVG 尺寸，deviceScaleFactor 2，
  omitBackground 透明底
- manifest 驱动批量导出（文件列表一个 json，脚本通用）
- 交付目录结构：`outputs/<project>/` 下 SVG 与 PNG 同名成对

## 常见坑（本项目全踩过）

| 坑 | 解法 |
|---|---|
| 图床同名缓存返回旧图 | 复制到全新文件名再上传 |
| 色条方角戳出圆角板 | clipPath 按板圆角裁切 |
| 渐变在 transform 组里失效 | userSpaceOnUse 坐标用元素局部坐标系 |
| 深色模式文档不可读 | color-scheme meta + 显式背景色 + 实测 |
| 评审页图片 404 | 路径相对包根（以 / 开头），服务根目录要起在包根 |
